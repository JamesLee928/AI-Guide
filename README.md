# AI問答導覽員

隨著行動裝置與人工智慧技術的快速發展，傳統導覽方式已逐漸無法滿足使用者對於即時性、互動性與個人化資訊的需求。本專題以「AI 問答導覽員」為主題，設計並實作一套結合 Beacon 導覽系統、影音播放機制以及大型語言模型（LLM）的智慧導覽手機應用程式。系統透過藍牙 Beacon 偵測使用者與導覽地點之距離，自動推播對應的導覽影音內容，並提供即時 AI 問答功能，使使用者能針對場域相關資訊進行自然語言提問，獲得即時且具情境性的回應。本研究著重於系統整合與實際應用層面，驗證 Beacon 定位技術與 LLM 問答機制在導覽場景中的可行性與實用價值，期望為智慧導覽應用提供一套可擴充且具參考價值的實作範例。
